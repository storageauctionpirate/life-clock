# Life Clock (working draft) — for Mike / Pirate
Single-file `index.html`, vanilla JS, localStorage only. All values (foods, minute rules, targets, badges) live in the `CONFIG` object at the top of the script.
Published to https://storageauctionpirate.github.io/life-clock/ via GitHub contents API (publish.sh).
Fun estimates, not medical advice.

## v2 (Oct 16 2026)
Per-serving food minutes from research (HENI, Stylianou 2021, plus others); new Habits tab (cravings beaten, activities, sun, salt, screens, sleep, cigarettes); ultra-processed foods take a penalty and whole foods get a small bonus; Sources tab. Backup of v1: index.backup-*.html
